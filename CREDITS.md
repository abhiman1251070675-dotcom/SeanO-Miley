# Credits & Acknowledgements

This project was built to push the boundaries of interactive web design, combining 3D elements with modern web development. It was heavily inspired by some of the most creative experiences on the internet.

## Design Inspiration

* **[Lando Norris Official Website](https://landonorris.com/)** – A major inspiration for the overall layout, typography, grid structure, and premium interactive feel of the experience.
* **[Myshaky](https://myshaky.com/)** – Inspired the creative direction and layout for the interactive "Fight Passport" and Vault cards.

## Technologies & Tools

* **[React Three Fiber](https://docs.pmnd.rs/react-three-fiber/) & [Three.js](https://threejs.org/)** – The core 3D engine powering the interactive UFC belt and the dedicated Observation Mode environment.
* **[React](https://react.dev/) & [Vite](https://vitejs.dev/)** – The frontend framework and blazing-fast build tool.
* **[Tailwind CSS](https://tailwindcss.com/)** – Used for all styling, hover animations, and responsive design.
