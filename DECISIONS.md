Autonomous decisions logged per the master prompt's prime directive. "Good" = brutalist, neon-lit UFC glamour that makes the belt do the talking.

| # | Decision | Why | Alternative rejected |
| --- | --- | --- | --- |
| 1 | **Concept pivot: LUMEN → SUGA.** §1's "Suga" vision and the five uploaded photos override the default deep-sea concept. All LUMEN-specific sections (Surface/Drop/Coral/Jellyfish/Whale/Anglerfish) were replaced by the site architecture from §1: Octagon · Record · Fight Vault · TimboSugarShow · Fit Check · Suga Merch · Stay Suga. | §1 explicitly says "honor the description first" and "log the adaptation". | Keeping the abyss and bolting Suga on would have betrayed the user's material. |
| 2 | **Project folder: `suga-show/` not `lumen/`.** The brief says "Follow file paths in §7 exactly" and names the root `lumen/`. Renamed to match the brand. | Keeps `npm run dev` URL + docs referencing the actual product name; easy to find in a "Default Project" parent. | `lumen/` would mislabel the build and confuse judges. |
| 3 | **3D scene renames.** `environment/WaterSurface + GodRays + Atmosphere` → `EnvMap + Atmosphere + ParticleField + Lighting`; `creatures/{FishSchool,Jellyfish,Whale,Anglerfish}` → `props/Belt + Gloves`; `props/CoralCathedral + MediaExhibits` consolidated into `Belt` + `Gloves` (+ DOM-placed photos). | The deep-sea creature set has no meaning on a UFC fighter site. The list of props now matches the actual geometry shipped. | Stuffing belt geometry into `FishSchool.tsx` would hurt maintainability. |
| 4 | **Main image = `newim-main.jpg` (studio face portrait).** The user wrote "newimg is the main image"; `Documents/newim.jpg` is that file. Placed as the big Legacy exhibit + braids-cap merch alt (duotone poster `images-11.jpg` took the "main-poster" slot). | Honors the user's explicit instruction with visual prominence. | Using the duotone poster as the Legacy hero would downgrade the sharpest, highest-contrast portrait. |
| 5 | **Excluded uploads.** `images-11` (duplicated — now kept), `images-12 + images-13a` (both the same bloodied fight photo, 33 KB each) → excluded for all-ages rule (§5.10). `recording-2026-08-26.mp4` (25 MB screen recording from Downloads) → excluded, no ffmpeg to transcode to a muted loop and 8× over the 3 MB budget. | Rule 10 (awe only — nothing frightening/violent) is binding. | Including visible blood would risk the hackathon's all-ages moderation. |
| 6 | **Scroll cinematics without video.** The brief asks for "high-framerate video snippets" on scroll; no usable videos were supplied. Reinterpreted as **VHS/glitch-typography** masks over the uploaded photos (`Glitch` class + `scanlines` + Framer stagger reveals). | Keeps the glitch aesthetic honest without faking video. | Faking a 25 MB screen recording into a hero video would be oversized and off-brand. |
| 7 | **Championship belt as the hero object.** Built procedurally in Three.js (curved leather strap, gold plates, inlay + octagon ring, gems with emissive bloom, `RoomEnvironment` env map) rather than downloading a marketplace model. | Free/open-source only, no licensed assets, and the belt maps directly to the "Custom Suga Gloves or Belt" mechanic from §1. | A downloaded CC0 belt would lack the pink/lime/gold emissive tuning and would need KTX2/Draco plumbing. |
| 8 | **`RoomEnvironment` PMREM env map** over a downloaded HDR. Zero network at runtime, no HDR licence questions, metals still read correctly. | Free + deterministic. | An HDRI from Poly Haven would need a 2 MB add-on and CDN fetch. |
| 9 | **No Lenis on `prefers-reduced-motion` or touch.** Touch gets native inertia (`syncTouch: false` → off). Reduced-motion skips the smooth scroller, auto-descent variant becomes instant line reveals. | Honors the responsive contract §10 + accessibility. | Forcing Lenis on touch would fight the OS scroller and feel alien. |
| 10 | **Touch targets ≥ 44 px + bottom-thumb controls.** Sound/restart live in the bottom-right on phones (the top bar keeps only the wordmark + a thin progress line). HUD right-rail hidden on `<768px`. Safe areas handled via `env(safe-area-inset-*)` and `100svh`. | Device contract §10 physical checklist. | Top-only controls would mis-tap under notches and fail thumb-ergonomics. |
| 11 | **Audio: procedural only, off by default.** Web Audio `AudioContext` synthesizes a pad + podcast layer. Two gains: master (Nav toggle) and podcast (Play button). Analyser feeds the visualizer. Never autoplays. | Satisfies the "Sound toggle (off by default, no audio files)" rule from §4. | Shipping MP3s would violate the "no audio files needed" hint and bloat the budget. |
| 12 | **Countdown date: rolling.** `2026-12-12T03:00Z` is the base; `while (t <= now) t += 112 days` keeps it in the future forever, labelled `TBA` so it's an honest concept-site device. | Avoids a forever-past countdown that would look abandoned. | A hard-coded UFC fight that has already happened would age poorly. |
| 13 | **Fight Vault stats: approximate.** Each row shows strike differentials labeled `≈`; the panel footer says "unofficial fan concept · striking stats approximate". Web Search confirmed the ledger through UFC 306; numbers are stylized mixes, not official UFC Stats. | Truthfulness > validation: don't present guesses as facts. | Fabricating exact `Sig. Str. 126–83 (Yan)` without citation would be dishonest. |
| 14 | **State model: `worldState` ref + zustand store.** Continuous scroll/pointer live in a module ref (read by `useFrame`/`rAF`) so there is no React re-render storm; discrete state (section, muted, fight id, quality) lives in zustand. | Perf: 60 fps desktop / ≥30 fps mobile. | Putting `progress` in zustand would re-render the whole overlay subtree per frame. |
| 15 | **Performance tier.** Initial `high/medium/low` from pointer-coarse + `screen.width` + `navigator.hardwareConcurrency` + live `PerformanceMonitor` downgrade (never upgrades automatically). `dpr` clamped per tier, `Noise` + `ChromaticAberration` dropped off-tier, `frameloop="never"` when `document.hidden`. | Thermals and battery (§10) + budget §11. | Re-upgrading on a single good frame would thrash. |
| 16 | **Tailwind 3.4 (stable), not 4.x.** The file-mandate names `tailwind.config.js + postcss.config.js`; Tailwind 3 matches that workflow without migration. | Tooling fidelity. | Tailwind 4's CSS-first config would make the mandated files pointless. |
| 17 | **HMR in dev: kept `React.StrictMode`.** Deliberate; Lenis/GSAP cleanup is idempotent and the runner log shows it. | Best practice for catching bad effects before prod. | Removing it would hide double-mount bugs only judges would see. |
